# Verdant — Emeraude 300

Luxury watch landing page with a scroll-scrubbed 3D disassembly hero.

- Plain HTML/CSS/JS, GSAP + ScrollTrigger + Lenis via CDN — no build step.
- The hero video (`assets/hero.mp4`) is decoded into a frame sequence on load for smooth scroll scrubbing.

## Run locally

```bash
node server.js
```

Open http://localhost:5173. Any static host works for deployment (GitHub Pages, Hostinger `public_html`, etc.).
